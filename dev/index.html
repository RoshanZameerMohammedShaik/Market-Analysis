🛠 Dev Hub off

Path-based dev mode. Visiting /dev turns it on for this browser; visiting /dev/off turns it off. Tools below are noise reduction, not security — anyone reading the source can flip them on.

Mode toggle

Dev mode persists in localStorage. While on, the app reveals extra diagnostics on the signal card, the Debug App chip, and skips some user-friendly fallbacks.

How to use

  1. Click Turn ON above. The page button updates to show the new state.
  2. Open the main app at /. A small 🛠 chip appears in the bottom-left corner of the app.
  3. Use the app normally. The chip silently captures every console message, uncaught error, promise rejection, and fetch failure — even ones that happen during page load.
  4. The chip's count badge (0E / 0W) updates live; border turns red on errors, yellow on warnings, so you'll see when something goes wrong without watching it.
  5. Click the chip to expand the panel. Search by substring, filter by level or source, copy the whole buffer (URLs and tokens auto-redacted), or clear to start fresh.
  6. To turn dev mode off, come back here and click Turn OFF. Or visit /dev/off as a shortcut.
