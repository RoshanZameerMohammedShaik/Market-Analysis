🛠 Dev Hub off

Path-based dev mode. Visiting /dev turns it on for this browser; visiting /dev/off turns it off. Tools below are noise reduction, not security — anyone reading the source can flip them on.

Mode toggle

Dev mode persists in localStorage. While on, the app reveals extra diagnostics on the signal card and skips some user-friendly fallbacks.

Debug App

Live view of every console message, uncaught error, promise rejection, and fetch failure across the whole app — captured from the moment the page loads. URLs and tokens are auto-redacted before they hit the buffer, so it's safe to copy or screenshot.
